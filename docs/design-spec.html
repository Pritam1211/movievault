MovieVault build spec

A personal film catalogue, not a streaming service. Every screen below is drawn to the tokens underneath it — build against these, then screenshot the emulator and we compare.

REACT NATIVE 0.87 · ANDROID · SUPABASE + TMDB

The idea

The UI is the dark room. The posters are the light.

Film posters are loud — saturated, high-contrast, fighting for attention by design. If the interface competes with them, both lose. So the chrome stays deep blue-black and near-silent, and every scrap of colour on screen comes from the artwork itself.

One exception: a tungsten amber, the colour of a projector bulb, reserved strictly for the thing you can act on right now. One accent, one job. When you see amber, you can tap it.

The ground is blue-black, not neutral grey — #0B0F14 against a plain #111 reads cooler and deliberately lit. bulb appears only on the primary button and the focused input border. Never as decoration, never as a heading colour.

System font throughout. Negative tracking on the two largest sizes only — it tightens display type and does nothing good below ~20px. No uppercase labels anywhere in the app; they read as chrome and this app has almost none.

Screen gutter is 28. Radius is 10 on inputs and buttons, 5 on posters, 99 on status pills. Three radii, each meaning a different kind of object — not one value stamped on everything.

Motion

Press scale on the primary buttonSpring to 0.97 on press-in, back on release. Confirms the tap before the network does.
Shake on failed sign-inFour steps: −8, +8, −5, 0 at 50ms each. Shows what changed, on the element that changed.
Fade the error in180ms. The text appearing instantly reads as a layout jump rather than a message.
Nothing animates on mountStaggered fade-and-slide entrances on every screen are the generic default. Motion here answers an action or it doesn't happen.

States to build

LoadingPoster-shaped placeholders in the grid, not a centred spinner. The layout shouldn't jump when data lands.
Empty watchlist"Nothing saved yet. Find something in Discover." — an invitation, naming the next action.
Search, before typing"Search by title." Nothing else — no popular suggestions, no recent searches until there are any.
Search, no results"No films match ‘xyz’." Name what was searched, so it's clear the query ran.
Network error"Couldn't reach TMDB. Check your connection and try again." plus a retry control. No apology, no vagueness.
Offline with cached dataShow the cached list with a quiet banner. Don't blank a screen that has content to show.
